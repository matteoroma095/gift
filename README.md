# Gift

Piccola esperienza web statica per presentare un regalo in modo interattivo.

## Struttura

- `index.html` — esperienza completa, mobile-first
- `assets/personal/` — fotografie usate come sfondi delle schermate
- `assets/treatments/` — immagini dei quattro trattamenti
- `.github/workflows/pages.yml` — deploy su GitHub Pages

Il sito non usa framework, build step o dipendenze esterne: HTML, CSS e JavaScript puro.

## Privacy / indicizzazione

La pagina include `noindex,nofollow,noarchive` e `robots.txt` blocca i crawler. La repository e l'URL GitHub Pages restano comunque pubblici se la repository è pubblica.
